# BurtsevWerk — burtsevwerk.eu

Static site: `index.html` + images.

## Deploy on Render
1. Push this folder to a GitHub repository.
2. Render → New → Static Site → choose the repo.
   - Build command: (empty)
   - Publish directory: `.`
3. Settings → Custom Domains → add `burtsevwerk.eu` and `www.burtsevwerk.eu`,
   then set the DNS records Render shows at your domain registrar.

## Before going public
- Create the mailbox `info@burtsevwerk.eu` (the form opens an email to it).
- Matronyan case: replace the `[screenshot]` placeholders and the demo link.
